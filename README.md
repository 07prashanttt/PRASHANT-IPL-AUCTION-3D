# PRASHANT IPL AUCTION 3D

A fan-made IPL-style auction simulator PWA. It is not affiliated with IPL/BCCI or the franchises.

## Run locally
Open `index.html` in a browser for basic play. For PWA install/offline service worker, serve the folder through GitHub Pages or a local static web server (service workers require HTTPS or localhost).

## GitHub Pages
1. Create a public repository named `PRASHANT-IPL-AUCTION-3D`.
2. Upload all files and folders from this project, keeping their folder structure.
3. Open Settings → Pages.
4. Set Build and deployment to Deploy from a branch, choose `main` and `/ (root)`, then Save.
5. Open the published HTTPS URL on Android Chrome and choose Install app / Add to Home screen.

## Current starter build
Includes franchise selection, ₹120 Cr team purses, nine rival AI bidders, bid increments, team ledger, 8 overseas-player restriction, 25-player squad limit, purchase list, custom Nepal players and local save/resume. The player list is a starter dataset, not a complete verified current IPL database. Verify/update player eligibility, base prices, and photo rights before publishing. Custom portraits are the user's supplied photos; no facial edits are applied in this build.
